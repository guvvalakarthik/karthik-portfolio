# Guvvala Karthik — Portfolio

An evidence-led portfolio for Guvvala Karthik, a Full-Stack AI Engineer graduating
from IIIT Kottayam in 2026.

## Local development

```powershell
npm install
npm run dev
```

## Validation

```powershell
npm test
npm run build
```

The public résumé source is `public/resume.html`; the downloadable PDF is generated
from that source so the visible portfolio and résumé stay consistent.
